# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

Participants must foster a welcoming, harassment-free environment. Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, and sustained disruption.

Report incidents to `conduct@example.com` before publication; replace that address with the project's conduct contact. Maintainers will review reports promptly and may remove content, issue warnings, or restrict participation when necessary.

The full Contributor Covenant 2.1 text is available at https://www.contributor-covenant.org/version/2/1/code_of_conduct/.
